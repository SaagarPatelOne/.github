# Contributing

Thanks for taking the time to contribute.

This organization is currently maintained by a solo owner, so the contribution process is intentionally lightweight.

Before opening a pull request:

- Search for an existing issue or pull request first.
- For bugs, include clear reproduction steps, expected behavior, and actual behavior.
- For changes that alter behavior, explain the user impact and any tradeoffs.
- Keep pull requests focused. Smaller changes are easier to review and merge.

Pull request expectations:

- Use a clear title and short summary.
- Link related issues when relevant.
- Include tests or manual verification notes when applicable.
- Call out risks, breaking changes, or follow-up work.

Not every proposal will be accepted, but thoughtful, well-scoped contributions are always appreciated.
