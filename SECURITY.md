# Security Policy

## Reporting a vulnerability

Please do not report active vulnerabilities in a public issue or discussion.

Preferred path:

- Use GitHub private vulnerability reporting when it is enabled on the affected repository.

Fallback path:

- Email `saagarpatel08@gmail.com` with the subject line `Security report`.
- Include the affected repository, impact, steps to reproduce, and any proof of concept that is needed to validate the report.

I will try to acknowledge valid reports within 5 business days.

## Scope

This guidance applies to repositories in the `SaagarPatelOne` organization unless a repository has a more specific security policy.
