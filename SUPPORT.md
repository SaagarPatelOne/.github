# Support

Use the right channel so requests can be handled efficiently.

- Bug reports: open an issue with reproduction details and impact.
- Feature requests: open an issue with the problem, use case, and expected outcome.
- Security concerns: follow `SECURITY.md` and avoid public disclosure.
- General questions: open an issue only if it is specific to the repository and actionable.

This organization is currently maintained by a solo owner, so response times may vary.
